# 约束与适用前提

## 1. 约束

以下为硬性约束，违反即为不合格实现：

1. **禁止**动态堆内存分配；
2. 容器容量**必须**固定（固定数组），**禁止**动态增长；
3. **必须**使用定点运算，**禁止**浮点；
4. **禁止**异常、RTTI 与虚函数；
5. MCU 端内存**必须**静态分配；
6. 框架与应用**禁止**调用具体平台的接口，平台相关调用**必须**只存在于平台服务实现中；
7. 语言标准为 C++17，**禁止**依赖更高标准。

## 2. 适用前提

适用范围由四条前提界定：

1. 状态到画面是单向的；
2. 音频为语音式：事件触发，声音连续播放至结束；
3. 输出目标是光栅显示；
4. 逻辑以固定节拍推进，状态以快照形式发布。

超出上述前提的应用属于另一个类别，本架构不作承诺。

## 3. 封闭判据

问题若能在应用内部与两条管道内解决，则为封闭问题，**禁止**为此修改架构；需要为骨架增加流程或增加通道时，方为溢出。
