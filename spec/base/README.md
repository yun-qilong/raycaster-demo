# base 规范

框架层规范分四份，本文件为索引、术语与限定词约定。

## 文档

| 文档 | 内容 |
|---|---|
| `frame.md` | 组件与分工、帧流程（含骨架/应用边界）、应用钩子、骨架规则 |
| `contract.md` | 平台契约：输入、信箱、队列、渲染内存、画面推送、时基 |
| `vocabulary.md` | 契约词汇：输入采样、状态快照、事件及其归属与规模 |
| `constraints.md` | 硬约束、适用前提、封闭判据 |

## 术语

| 术语 | 定义 |
|---|---|
| 框架 | 定义固定流程与契约的部分，不含任何具体应用、具体平台的内容 |
| 骨架 | 框架在每个帧流程中固定执行的步骤 |
| 应用 | 实现变化点的部分（含组件与契约词汇） |
| 组件 | 应用侧的行为件：主逻辑、渲染逻辑、声音逻辑（预留） |
| 平台服务 | 平台按契约提供的服务集合 |
| 组装 | 构造部件并建立连接的宿主侧部分，唯一同时了解应用与平台 |
| 宿主 | 驱动框架的外部环境，承担循环、等待与节奏 |
| 帧 | 一个组件被驱动一次所执行的完整流程 |
| 主逻辑 | 推进世界状态的组件 |
| 渲染逻辑 | 由状态快照产出画面的组件 |
| 声音逻辑 | 由事件产出声音的组件（预留） |
| 信箱 | 承载状态快照的通道，覆盖语义 |
| 队列 | 承载事件的通道，逐条语义 |
| 快照 | 世界状态在一个逻辑时刻、仅供渲染读取的视图 |

## 限定词

本规范全文使用四种限定词，含义固定：

| 词 | 含义 |
|---|---|
| **必须** | 硬性要求；违反即实现不合格 |
| **禁止** | 硬性禁止；违反即实现不合格（等价于"必须不"） |
| **应当** | 推荐要求；违反需说明理由 |
| **可以** | 允许；实现可自行选择 |

未使用限定词限定的描述性语句不构成契约。
