# Raycaster Demo — 目标文档

## 一句话目标

用**纯光线投射**（Wolf3D-Like）渲染一张 **2.5D 地图**，玩家用**键盘鼠标**在**地图中自由行走**，运行于 Linux/Windows（SDL2），并严格保持**可移植约束**（无堆 / 定点数 16.16 / 平台抽象），为后期完整版移植 Cortex-M7 铺路。

## 功能清单（MVP）

### 1. 地图
- 2D 网格地图（经典 Wolf3D 风格布局：外墙 + 内墙 + 房间，如 24×24）
- 地图数据以**静态常量数组**表达（无堆；可由 tools/ 资产管线生成）
- 墙体区分类型（砖墙 / 石墙等），为纹理贴图留口

### 2. 光线投射 2.5D 渲染
- 屏幕逐列发射射线，**DDA 算法**求墙距离（定点数实现，无 float）
- **垂直距离校正**（消除鱼眼变形）
- 按距离渲染墙条带高度（近大远小）
- 起步纯色墙；纹理贴图作为后续增强
- 地板 / 天花板（单色，可选）

### 3. 键鼠操控行走
- **WASD**：前进 / 后退 / 左右横移，带**碰撞检测**（不可穿墙）
- **鼠标**：水平移动转向（相对模式、隐藏光标）
- **Esc** / 窗口关闭：退出
- 帧率控制 + delta 时间归一化移动速度

### 4. 工程形态
- 游戏主循环：事件 → 更新 → 渲染 → 呈现
- 输入 / 平台走 `Platform` API 抽象（当前已具备雏形，需扩展按键/鼠标）
- 渲染核心在 `src/core/`（平台无感、零平台宏、无堆）
- CI / 提交规范沿用现有（Issue 引用、Jenkins/Gerrit 流程）

## 范围界定

- **MVP 包含**：地图 + 2.5D 光线投射画面 + 键鼠行走 → 可玩的最小闭环
- **MVP 不包含**：多纹理贴图、音效、敌人/NPC、开枪射击、地图编辑器、存档

## 后续增强（MVP 之后）

- 墙纹理贴图（tools/ 转 C 数组）
- 2D 小地图调试窗
- FPS / 帧耗时显示
- 距离暗化 / 雾效
- 视角上下（look up/down）等扩展
